# PropertyHub — Frontend

The React frontend for PropertyHub, a full-stack property management
system built as a portfolio project. Landlords, tenants, and admins
can manage properties, tenants, and maintenance requests through this
interface, which talks to a Spring Boot REST API backed by PostgreSQL.

## Tech stack
- React (Vite)
- React Router
- Axios / Fetch for API calls

## Getting started

```bash
npm install
npm run dev
```

Runs the app locally at `http://localhost:5173` by default.
